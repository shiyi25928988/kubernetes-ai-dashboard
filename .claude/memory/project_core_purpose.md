**Fact:** This is an AI Agent-driven MPI task scheduling platform for solver computing applications. Solver jobs run as `mpi-job` workloads on Kubernetes.

**Why:** The platform is designed to intelligently schedule and manage high-performance MPI computing tasks for solver applications, using AI/LLM agents to optimize scheduling decisions and operations.

**How to apply:** When developing features, prioritize functionality that supports MPI job lifecycle management on Kubernetes, AI agent-driven scheduling optimizations, and integration with solver computing workloads.
